# python-owen #

Библиотека для работы с приборами фирмы [Овен] по протоколам Modbus и ОВЕН

Поддерживаются:

| Измерители | ПИД-регуляторы | Программные задатчики | Регуляторы | Счетчики импульсов | Тахометры | Модули ввода-вывода | Драйверы ШД | Программируемые реле |
| :--------: | :------------: | :-------------------: | :--------: | :----------------: | :-------: | :-----------------: | :---------: | :------------------: |
| ТРМ200     | ТРМ10          | ТРМ151                | ТРМ136     | СИ8                | ТХ01      | МВ110               | MST24       | ПР103                |
|            | ТРМ101         | ТРМ251                | ТРМ138     | СИ30               |           | МК110               | MST34       |                      |
|            | ТРМ148         |                       | ТРМ201     | СИ130              |           | МУ110               |             |                      |
|            | ТРМ210         |                       | ТРМ202     |                    |           | МЭ110               |             |                      |
|            | ТРМ212         |                       | 2ТРМ1      |                    |           | МВ210               |             |                      |
|            |                |                       | 4ТРМ1      |                    |           | МК210               |             |                      |
|            |                |                       |            |                    |           | МУ210               |             |                      |

Возможна поддержка других моделей путем добавления настроек в папку `owen/device`

Не со всеми моделями проверена работа библиотеки

[Овен]:   https://owen.ru
